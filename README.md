
# Jumpmark Dock

URLごとに双方向ショートカット（Jumpmark）を設定・管理できるChrome拡張機能です。

## 🚀 機能

### 基本機能
- **双方向リンク**: A→Bを作成すると、B→Aも自動で作成
- **Chrome Sync対応**: 複数デバイス間でJumpmarkを自動同期
- **バッジ表示**: 現在のページにJumpmarkがある場合、拡張機能アイコンに数を表示
- **スマートなタブ管理**: 同じURLのタブがあればフォーカス、なければ新タブを作成
- **編集・削除機能**: 既存のJumpmarkを編集・削除可能
- **開いているタブから入力**: 追加フォームで開いているタブを選ぶと、タイトルとURLを自動入力
- **直感的なUI**: シンプルで使いやすいポップアップインターフェース

### 🆕 v1.1.0 新機能
- **📤 インポート/エクスポート**: JSON/CSV/HTML形式でデータのバックアップ・復元
- **📁 ドラッグ&ドロップ**: ファイルを直接ドロップしてインポート
- **🔍 重複検出**: インポート時の自動重複チェックとマージオプション
- **🎨 高度な管理UI**: オプションページでの一括操作と検索・フィルタリング
- **🌙 ダークモード**: システム設定に応じた自動テーマ切り替え

### 🆕 v2.0.0 新機能
- **🃏 ワイルドカードURLサポート**: 作成元URLの末尾に `*` を指定することで、ディレクトリ配下やサブドメインの全ページで表示される共通Jumpmarkを作成可能に
- **🔗 逆方向プロトコルの高度な保持**: IPv6（ULA/リンクローカル/ループバック）やポート番号付きローカル環境（`localhost:3000`, `*.local:8080`）で、プロトコル（`http://`）を正確に自動維持・フォールバック
- **🏗️ アーキテクチャの堅牢化 (リファクタリング)**: URL/パターン解析処理を一元化する共通パーサー (`parseUrlPattern`) の導入、および UI 状態管理と状態遷移の明確な分離

### 🆕 v2.1.0 新機能
- **🔖 新規追加フォームの簡略化**: `popup.html` で新規作成時のアイコン入力欄を非表示化
- **💾 保存値の明確化**: 新規保存時の `icon` を `🔖` で明示保存
- **✏️ 編集体験の維持**: 編集モードでは従来どおりアイコン入力欄を表示して変更可能

### 🆕 v2.2.0 新機能
- **🌐 英語UI対応**: Chromeの表示言語設定に追従し、日本語以外の環境では英語UIを表示
- **🏗️ i18n基盤の導入**: `_locales/` ベースの `chrome.i18n` を導入し、ロケールを追加するだけで他言語にも拡張可能
- **📅 表示言語に追従した日付表示**: 画面表示・エクスポートファイル内の日付フォーマットが表示言語に追従

### 🆕 v2.3.0 新機能
- **🗂️ 開いているタブから入力**: 追加フォームの「開いているタブから選ぶ」から、開いているタブを選ぶだけでタイトルとURLを自動入力
- **🔒 必要なときだけ読み込み**: タブ情報は一覧を開いたときだけ読み込み、現在のタブ・`http(s)` 以外のページ・シークレット状態の異なるタブは一覧に出さない

## 📦 インストール

### Chrome ウェブストアから（推奨）

[Chrome ウェブストア](https://chromewebstore.google.com/detail/jumpmark-dock/ldodfncboddjjbggcholbmkmjbfjmblh)からインストールできます。

### 開発者向け（パッケージ化されていない拡張機能として）

1. このリポジトリをクローン
   ```bash
   git clone https://github.com/maepon/jumpmark-dock.git
   cd jumpmark-dock
   ```

2. Chromeで `chrome://extensions/` を開く

3. 右上の「デベロッパーモード」をON

4. 「パッケージ化されていない拡張機能を読み込む」をクリック

5. `jumpmark-dock` ディレクトリを選択

## 🎯 使い方

### Jumpmarkの追加

1. 拡張機能アイコンをクリック
2. 「+ Jumpmarkを追加」ボタンをクリック
3. タイトルとURLを入力（新規追加時のアイコンは `🔖` が自動設定されます）
   - 「開いているタブから選ぶ」を開き、一覧からタブを選ぶとタイトルとURLが自動入力されます（一覧を開いたときだけタブ情報を読み込みます）
4. 「双方向リンク」をチェック（推奨）
5. 「保存」をクリック

### Jumpmarkの使用

- 拡張機能アイコンをクリックしてJumpmarkリストを表示
- 移動したいJumpmarkをクリック
- 同じURLのタブがあればフォーカス、なければ新タブで開く

### Jumpmarkの編集・削除

- Jumpmarkアイテムにマウスホバーでボタンが表示
- 「編集」ボタンで内容変更、「削除」ボタンで削除
- 編集時はアイコンを含む各項目の変更が可能
- 編集時も双方向リンクの設定が可能

### バッジ表示

現在のページにJumpmarkがある場合、拡張機能アイコンに青いバッジで数が表示されます。

### 🆕 インポート/エクスポート（v1.1.0）

#### データのエクスポート
1. 拡張機能アイコンを右クリック → 「オプション」
2. 「インポート/エクスポート」タブを選択
3. エクスポート形式を選択（JSON/CSV/HTML）
4. エクスポート範囲を指定（すべて/選択済み/フィルタ結果）
5. フォーマットボタンをクリックして自動ダウンロード

#### データのインポート
1. オプションページの「インポート/エクスポート」タブ
2. JSONファイルをドラッグ&ドロップ、または「ファイルを選択」
3. インポート設定を確認（既存データとの統合/重複スキップ）
4. プレビューで内容を確認
5. 「インポート実行」をクリック

#### 対応フォーマット
- **JSON**: 完全なデータ形式（推奨）- インポート/エクスポート両対応
- **CSV**: 表計算ソフト用 - エクスポートのみ
- **HTML**: ブラウザ表示用 - エクスポートのみ（`http`/`https` 以外の URL はリンクにせずテキストとして表示）

## 🏗️ アーキテクチャ

```
jumpmark-dock/
├── manifest.json       # 拡張機能の設定
├── background.js       # バックグラウンドスクリプト（バッジ管理）
├── popup.html         # ポップアップUI
├── popup.js           # ポップアップロジック
├── popup.css          # ポップアップスタイル
├── options.html       # オプションページUI（v1.1.0）
├── options.js         # オプションページロジック（v1.1.0）
├── options.css        # オプションページスタイル（v1.1.0）
├── shared.js          # 共通ユーティリティ関数
├── i18n.js            # 静的DOMへの多言語メッセージ適用（v2.2.0）
├── _locales/          # chrome.i18n用のメッセージリソース（v2.2.0）
├── icons/             # アイコンファイル
├── CLAUDE.md          # Claude Code開発ガイド
└── README.md          # このファイル
```

### 主要コンポーネント

- **popup.js**: 基本的なJumpmarkの管理とUI制御
- **options.js**: 高度な管理機能（インポート/エクスポート、一括操作）
- **background.js**: タブ監視とバッジ更新
- **shared.js**: URL正規化や共通ユーティリティ関数
- **i18n.js**: `data-i18n*` 属性を持つ静的DOM要素への翻訳メッセージ適用
- **Chrome Storage Sync API**: Jumpmarkデータの永続化と同期

### データ構造

```javascript
{
  "jumpmarks": {
    "example.com/page1": [
      {
        "id": "jm-unique-id-123",
        "title": "関連ページ",
        "url": "https://example.com/page2",
        "icon": "📝",
        "sourceUrl": "example.com/page1",
        "created": "2025-06-30T10:00:00Z"
      }
    ]
  }
}
```

**v1.1.0の変更点**: `bidirectional`フラグを廃止し、`sourceUrl`でURL間の関係を動的に検出する方式に変更。
**v2.0.0の変更点**: ワイルドカード付きのジャンプマークオブジェクトに `isWildcard: true` フラグを付与。また、URLパーサーの一元化およびUI状態更新ロジックのリファクタリングを実施。

## 🔄 Chrome Sync機能

- **自動同期**: Chrome Syncが有効な場合、Jumpmarkデータが複数デバイス間で自動同期
- **フォールバック**: Chrome Syncが無効な場合、ローカルストレージとして動作
- **制限事項**: `chrome.storage.sync` の上限は全体102,400バイト・1項目8,192バイト・最大512項目。本拡張機能は全データを `jumpmarks` の1項目に保存しているため、実際には全体で約8KBが上限
- **リアルタイム更新**: 他デバイスでの変更が即座に反映
