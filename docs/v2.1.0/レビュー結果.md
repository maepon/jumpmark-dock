## 3. 指摘事項・不整合の詳細

### 3.1 【重要度：高】 `popup.html` フォーム共用構造による編集画面機能の破壊および実行時エラー

- **問題の発生場所**:
  - `popup.html` (`#formView` / `#jumpmarkForm`)
  - `popup.js` (`showFormView`, `editJumpmark`, `submit` イベントハンドラ)
- **詳細**:
  `popup.html` 内のフォーム (`#jumpmarkForm`) は、**「新規追加」と「編集」の両方で使い回される共有要素**です。
  `実装計画書.md` Step 2 に書かれている通りに `popup.html` から `<input id="jumpmarkIcon">`（または親要素の `.form-group`）を完全に削除してしまうと、以下の重大な問題が発生します。
  1. **編集画面でアイコンが変更不能になる**:
     `仕様書.md` の「3.4 編集画面の仕様（既存の編集UIをそのまま利用する）」および「5. 受け入れ条件 4（編集画面でアイコン変更が従来どおり可能である）」を満たせなくなります。
  2. **`TypeError`（実行時例外）が発生する**:
     `popup.js` の `editJumpmark` 関数内（268行目付近）で `document.getElementById('jumpmarkIcon').value` を参照しているため、`null` 参照エラーが発生し、ポップアップ画面の機能が停止します。
- **解決策**:
  `popup.html` から要素を完全削除するのではなく、**新規追加時（`showFormView`）はアイコン入力欄を非表示（`hidden`化）、編集時（`editJumpmark`）は表示**する動的制御に変更します。

---

### 3.2 【重要度：中】 `popup.js` における保存データ構築時のアイコン決定ロジックの明示化

- **詳細**:
  `shared.js` の `saveJumpmark` では `jumpmarkData.icon` が未設定の場合に `'🔗'` を補完します。
  `仕様書.md` の「新規登録時に `🔖` を明示保存する」を満たすため、`popup.js` のフォーム送信処理 (`submit` ハンドラ) で `icon` の値を次のように明示的に判定・設定する必要があります。
  - **新規追加時 (`!editingJumpmark`)**: `icon: '🔖'`
  - **編集時 (`editingJumpmark`)**: フォーム入力値（未入力の場合は既存アイコンまたは `'🔖'`）

---

### 3.3 【重要度：低】 手動確認項目の補完

- **詳細**:
  新規追加モードと編集モードの切り替え動作に関するクロスチェックテスト項目を追加することを推奨します。

## 4. 各ドキュメント修正案 (Diff / 修正文言)

### 4.1 `仕様書.md` 修正案

```diff
  ### 3.1 新規登録時のUI
  
- - `popup.html` の新規追加フォームからアイコン入力欄を削除する。
+ - `popup.html` の新規追加フォーム表示時、アイコン入力欄（`.form-group`）を非表示にする。
  - 補助文言（例: 「アイコンは作成後に編集画面で変更できます」）は表示しない。

  ### 3.4 編集画面の仕様
  
- - 既存の編集UIをそのまま利用する。
+ - `popup.html` および `options.html` の編集モードでは、従来どおりアイコン入力欄を表示し、編集可能とする。
```

---

### 4.2 `実装計画書.md` 修正案

```diff
  ### Step 2: UI修正（`popup.html` / `popup.js`）
  
- - 新規追加フォームのアイコン入力欄を削除する。
+ - `popup.html` のアイコン入力欄グループに識別用ID（例: `id="iconFormGroup"`）を設定する。
+ - `popup.js` の `showFormView()` にて `iconFormGroup` を非表示 (`hidden` クラス追加) にする制御を追加する。
+ - `popup.js` の `editJumpmark()` にて `iconFormGroup` を表示 (`hidden` クラス削除) にする制御を追加する。

  ### Step 3: 保存処理修正（`popup.js`）
  
- - 新規登録時の保存データに `icon: "🔖"`（既存キー名に合わせる）を必ず設定する。
+ - フォーム送信時、新規登録モード (`!editingJumpmark`) の場合は保存データに `icon: "🔖"` を明示的に設定する。
+ - 編集モード (`editingJumpmark`) の場合は入力されたアイコン値を適用する。

  ### Step 5: 手動確認
  
  1. `popup.html` の新規追加フォームにアイコン入力欄が表示されないこと。
  2. 新規登録した Jumpmark の保存データに `🔖` が入ること（双方向リンクの相手側にも `🔖` が設定されること）。
  3. 既存のアイコン未設定 Jumpmark が変化しないこと。
  4. 編集画面で従来どおりアイコン変更できること（新規追加後に編集ボタンを押した際にアイコン欄が表示され変更できること）。
```
