# v2.1.0 仕様書

## 1. 目的

Jumpmark の新規登録体験を簡略化するため、`popup.html` の新規追加フォームではアイコン入力欄を表示せず、登録時にデフォルト絵文字 `🔖` を自動設定する。

## 2. 適用範囲

- 対象画面: `popup.html` の新規追加フォームのみ
- 非対象画面: `options.html` 側の追加UI

## 3. 仕様詳細

### 3.1 新規登録時のUI

- `popup.html` の新規追加フォーム表示時、アイコン入力欄を非表示にする。
- 補助文言（例: 「アイコンは作成後に編集画面で変更できます」）は表示しない。

### 3.2 新規登録時の保存仕様

- 新規登録時、保存データにアイコン値として `🔖` を必ず明示的に保存する。
- 保存時のデータ構造は既存スキーマに従い、アイコン項目の値のみ本仕様に合わせる。

### 3.3 既存データの扱い

- 既存の「アイコン未設定 Jumpmark」はそのまま維持する。
- マイグレーション（既存データへの `🔖` 補完）は実施しない。

### 3.4 編集画面の仕様

- 既存の編集UIをそのまま利用する。
- `popup.html` および `options.html` の編集モードでは、従来どおりアイコン入力欄を表示し、編集可能とする。
- アイコン変更方法・入力方式・バリデーション強化などの追加変更は行わない。

## 4. 非機能・制約

- 既存機能への影響を最小化するため、変更は新規登録導線（`popup.html` 起点）のみに限定する。
- データ互換性維持のため、保存スキーマ自体は変更しない。

## 5. 受け入れ条件

1. `popup.html` の新規追加フォームにアイコン入力欄が表示されない。
2. `popup.html` から新規作成した Jumpmark の保存データに `🔖` が入る。
3. 既存のアイコン未設定データは変更されない。
4. 編集画面でアイコン変更が従来どおり可能である。
