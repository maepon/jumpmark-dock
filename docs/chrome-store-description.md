## アイテム紹介

**Jumpmark Dock** は、**Scoped Bookmark**（スコープ付きブックマーク）を実現する Chrome 拡張機能です。

普通のブックマークは、どのページを開いていても同じ一覧が表示されます。Jumpmark Dock で作るブックマーク（Jumpmark）は、作成元のページ（スコープ）にひも付き、そのページを開いたときだけ表示されます。「このページを見ているときは、いつもあのページに行きたい」という移動を、ブックマークバーを埋めずに用意できます。

考え方の紹介: [ブックマークにスコープを ― Scoped Bookmark という考え方](https://maepon.blog/about-scoped-bookmark/)

### 単一用途
ページやURLパターンにひも付けたブックマーク（Jumpmark）を、そのページを開いたときだけ表示し、関連するページへすぐに移動できるようにする。

### 主な機能
- **ページごとの Jumpmark**: 今開いているページに Jumpmark を作成し、そのページを開いたときだけポップアップに表示
- **双方向リンク**: A→B を作るときに、B→A の戻りの Jumpmark も一緒に作れる（初期状態でオン）
- **ワイルドカード**: 作成元URLの末尾に `*` を付けると、スコープをそのパス配下の全ページに広げられる
- **バッジ表示**: 今のページに Jumpmark があると、拡張機能アイコンに件数を表示
- **既存タブへの切り替え**: 移動先のページがすでに開いていれば、そのタブに切り替え
- **開いているタブから入力**: 追加フォームで開いているタブを選ぶと、タイトルとURLを入力
- **管理画面**: すべての Jumpmark の検索・絞り込み・編集・まとめて削除、JSON でのバックアップと復元
- **Chrome Sync による同期**、**日本語・英語の UI**、**ダークモード**

## 従来のブックマークとの違い

| | 従来のブックマーク | Jumpmark Dock |
|------|-------------------|---------------|
| 表示される場所 | どのページでも同じ一覧 | **作成元のページ（スコープ）でだけ表示** |
| 整理のしかた | フォルダに分けて、自分で探しに行く | **ページにひも付けておき、そのページで向こうから出てくる** |
| スコープの広さ | ― | **1ページだけ、またはパス配下（ワイルドカード）** |
| 戻りのリンク | 自分で別に作る | **作るときに一緒に作れる** |
| 気づき方 | ブックマークバーやメニューを開く | **アイコンのバッジに件数を表示** |

## 利用シーン

- ChatGPT のスレッドごとに、参照中のドキュメントやブログの下書きへのリンクを置く
- Notion のページに、関連する記事や GitHub の Issue をひも付ける
- GitHub のリポジトリ配下（`github.com/owner/repo*`）のどのページからでも、ドキュメントやデプロイ先へ移動する
- ステージングと本番、管理画面と公開ページなど、対になるページを行き来する
- 論文と参考文献、教材と演習問題など、本文と資料を往復する

## プライバシー・セキュリティ
- **最小限の権限**: 必要な権限のみ（ストレージ、タブ情報）
- **ブラウザ内での処理**: Jumpmark の保存・表示・照合はブラウザ内で行い、本拡張機能が独自に外部サーバーへ送信することはありません（Chrome同期を有効にしている場合の、Googleを経由した同期を除く）
- **拡張機能専用のストレージ**: データはChromeの拡張機能用ストレージに保存され、他の拡張機能やWebサイトからは読み取れません
- **オープンソース**: GitHubで公開しています

## 権限が必要な理由

この拡張機能では以下の権限を最小限必要とします：

### 🗄️ storage権限
**理由**: 作成したショートカット情報を保存・同期するため
**用途**: 
- ページ間のショートカットリンク情報をChromeの拡張機能用ストレージ（`chrome.storage.sync`）に保存
- Chrome同期機能により複数デバイス間でショートカットデータを共有
- データはChromeの拡張機能用ストレージに保存され、他の拡張機能やWebサイトからは読み取れません

### 📄 tabs権限  
**理由**: 現在のページ情報の取得に加え、バッジ表示・既存タブへの切り替え・タブ一覧からの入力にもタブ情報を使うため
**用途**:
- ポップアップを開いたとき、現在のウィンドウのアクティブタブのURL・タイトルを取得してショートカットを表示・作成
- バッジ表示のため、開いているすべてのタブのURLを、保存済みのショートカットとブラウザ内で照合（インストール時・起動時・データ変更時、および各タブの遷移・切り替え時）
- ショートカットを開くとき、同じURLのタブがあればそのタブに切り替えるため、開いているタブのURLを参照
- 追加フォームで「開いているタブの一覧」を開いたときだけ、その時点のタブのタイトル・URLを読み込んで表示（一覧を開いていないときは読み込みません）

**制限**:
- 参照したタブのURL・タイトルは、ユーザーがショートカットとして登録した場合を除き保存しません
- 参照したタブのURL・タイトルを、本拡張機能が独自に外部へ送信することはありません（登録したショートカットのChrome同期を除く）
- 閲覧の記録・追跡は行いません（バッジ更新のためにタブの変更を検知しますが、記録・送信はしません）
